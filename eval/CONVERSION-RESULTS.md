# MyFile conversion-suggestion evaluation

Live model calls (not mocked). Each case sends a request about a real file through the app's own prompt, schema and `check_suggestion`. **AI pick** is what the model answered; **MyFile accepted** is what the app did with it (an id, `none`, or `rejected` for a malformed answer). For cases marked *run*, the file was then converted with the accepted pick and the output's format was detected from its contents. Every prompt was also checked to contain neither the file's name nor its text.

Generated by `cargo test eval_conversion_live -- --ignored --nocapture`. Automated unit tests for the same rules (malformed answers, unknown ids, unsupported targets) are listed in [TESTS.md](TESTS.md).
